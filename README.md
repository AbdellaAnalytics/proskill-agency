# ProSkill Agency — نظام الإدارة الداخلي

React 18 + Vite + Supabase — منشور على Vercel من فرع `main`.

- الكود كله في `src/App.jsx`
- الداتا في جدول `proskill_workspace` (صف JSON واحد لكل workspace)
- `supabase/store_sale_inbox.sql` — جدول طلبات المتجر اللي بيظهر في تاب Sale Intake (اتشغّل قبل كده)

## Vercel
- Root Directory: **فاضي** (جذر الريبو) — مش أي مجلد جوّاه
- Build: `npm run build` · Output: `dist`
